# LLM CONTEXT PROMPT FOR CIRCULAR ECONOMY MARKETPLACE PROJECT

Copy and paste this entire prompt when starting a new LLM session to work on this project.

---

## PROJECT CONTEXT

I am working on a **Circular Economy Marketplace** - a full-stack web application that connects surplus material owners (sellers) with seekers (buyers) to enable material reuse and reduce environmental waste. The platform tracks sustainability impact (CO2 saved, waste diverted) and provides AI-powered suggestions for material reuse.

### Tech Stack

**Backend (Already Built):**
- Node.js + Express.js on port 5001
- MongoDB with Mongoose ODM
- JWT authentication (access + refresh tokens)
- GeoJSON for geospatial queries (2dsphere indexes)
- All API endpoints are complete and functional

**Frontend (Partially Built):**
- React 19 + TypeScript + Vite
- TailwindCSS v4 (dark theme with emerald/teal accent colors)
- Redux Toolkit for state management
- React Router v7
- Framer Motion for animations
- Leaflet + react-leaflet for maps
- Axios for API calls

### Design System

The app uses a **dark eco-tech theme**:
- Background: `neutral-950` (#0a0a0a)
- Card backgrounds: `neutral-900/50` with `border-neutral-800/50`
- Primary accent: Emerald (`emerald-500`, `emerald-400`)
- Secondary accent: Teal (`teal-500`)
- Text: White, `neutral-300`, `neutral-400`, `neutral-500`
- Gradients: `from-emerald-500 to-teal-500`
- Rounded corners: `rounded-xl`, `rounded-2xl`
- Glass effects: `backdrop-blur-sm`

### Key Data Models

1. **User**: email, name, role (buyer/seller/ngo/logistics_partner/admin), location, address, impactStats, rating
2. **Material**: title, description, category, condition, quantity, images, location (GeoJSON), address, price, priceType, status
3. **MaterialRequest**: material, requester, supplier, quantityRequested, status, messages
4. **Transaction**: request, material, supplier, receiver, status, impactMetrics (weightDiverted, co2Saved)
5. **Category**: name, slug, icon (emoji), impactFactor

### Critical Notes

1. **Coordinates**: 
   - MongoDB stores [longitude, latitude] (GeoJSON standard)
   - Leaflet uses [latitude, longitude]
   - ALWAYS convert between formats

2. **Authentication**:
   - Token stored in localStorage as `accessToken`
   - API client adds `Authorization: Bearer <token>` header
   - Use `GET /api/auth/me` to restore session

3. **API Base URL**: `http://localhost:5001`

4. **Standard Response Format**:
   ```typescript
   { success: boolean, message?: string, data?: T }
   ```
